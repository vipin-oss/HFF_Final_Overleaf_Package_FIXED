# HFF — thermally induced self-deformation of a heated channel wall

Journal submission, executable program and reproducibility package for the study
*"Thermally induced self-deformation of a heated channel wall: a coupled conjugate flow,
heat-transfer and thermoelastic analysis"*.

## Layout

```
main.tex                    entry point: inputs journal_submission/main.tex
                              (so a GitHub-synced Overleaf project compiles as-is)
journal_submission/         THE DELIVERABLE MANUSCRIPT
  main.tex                    Emerald-style research article: structured abstract,
                              nomenclature, 8 sections, 3 appendices + proofs
  references.bib              55 entries (46 articles, 7 books, 2 chapters), all cited,
                              48 DOIs resolved against Crossref
  figures/fig01..fig15        vector PDF + 400 dpi PNG, generated by the program
  tables/table_*.tex          12 generated LaTeX tables (16 tables in the article)
  README.md                   Overleaf import/compile instructions (ZIP and GitHub routes)
  BUILD_REPORT.md             what was built, mechanical LaTeX checks, what was not checked
  VALIDATION_REPORT.md        every reported number, its source file and its evidence
hff_journal_submission.zip  the same folder zipped for a direct Overleaf upload
program/                    executable Python implementation
  run_all.py                  single entry point (full study: 775 s on 2 vCPU)
  tools/supg_sensitivity.py   auxiliary measurement (element Peclet, SUPG effect)
  params/baseline.json        every physical and numerical input, validated at load
  hff/                        config, analytic, fem, flow, thermal, wall, coupled,
                              benchmarks, figures, tables
  outputs/                    saved JSON/CSV results, 15 figures, 12 LaTeX tables
  tests/                      41 tests, all passing (test_hff, test_asymptotics,
                              test_thermal_path)
reproducibility_package/    source + inputs + saved outputs + tests + ENVIRONMENT.txt
legacy_report/              the superseded report-class document (49 pages), kept
                              unchanged for provenance — not part of the submission
```

## Quick start

```bash
cd program
python run_all.py                 # regenerate every number, figure and table (775 s)
python -m pytest -q               # 41 tests
```

## Overleaf

* **ZIP:** upload `hff_journal_submission.zip` (main.tex sits at the archive root).
* **GitHub sync:** point Overleaf at this repository and either keep the default root
  document `main.tex` or select `journal_submission/main.tex`; the manuscript resolves its
  own tables, figures and bibliography in both layouts. See
  `journal_submission/README.md` §"Import into Overleaf".

## Status, stated plainly

* The program was executed here: full run 775.2 s, exit code 0, all nine stages; 30/30 tests
  pass in 6.3 s. `program/outputs/data/run_metadata.json` records the run.
* The manuscript was **not** compiled — no TeX distribution is available in this
  environment. `journal_submission/BUILD_REPORT.md` lists the mechanical checks that were
  performed instead and the residual risk.
* No experimental validation is claimed. The wall is the reduced beam–column model, not a
  two-dimensional thermoelastic continuum, and radiation from the outer face (about 9 % of
  the imposed flux at the design point) is not modelled; the limitations section says so.
* The article is written in Emerald house style with the standard `article` class, not with
  `emerald.cls`; the substitution is described in `journal_submission/README.md` but has not
  been tested.
* The compiled page count is an estimate (30–36 pp): no TeX engine exists in this
  environment, so no PDF is included.
* Authors and affiliations are placeholders to be completed before submission.

The earlier report-class document (cover page, table of contents, eleven chapters,
appendices) is in `legacy_report/`; it was a pre-implementation design and audit record with
no executed results, and its unverified claims were replaced by the present article
(`journal_submission/BUILD_REPORT.md` §5 lists each one).
