# HFF manuscript package — thermally induced wall deformation in a laminar channel

Target journal: *International Journal of Numerical Methods for Heat & Fluid Flow* (HFF, Emerald).
Title: *Thermally induced deformation and conjugate heat transfer in a channel with a thermoelastic wall:
formulation, reduced-order analysis and finite-element verification.*

**Scope.** Formulation, closed-form (reduced-order) analysis and finite-element verification of the **wall only**.
The coupled fluid–structure–thermal solver is **specified, not executed**: no coupled result is reported and every
flow-side number is labelled a reduced-order estimate. See `VALIDATION_REPORT.md` for what was tested and what was not.

## Rebuild

```bash
pip install -r code/requirements.txt     # numpy, scipy, matplotlib, scikit-fem  (Python >= 3.10)
./build.sh                               # solvers -> numbers/tables/figures -> pdflatex/bibtex x3
python3 code/check_manuscript.py         # must report 0 failed
```
Needs `pdflatex`, `bibtex`, `pdftops` (TeX Live 2023 used). The numerical part takes a few minutes.
Overleaf: upload this folder, set the main file to `main.tex`; keep `numbers.tex`, `tab_*.tex` and `figures/`.
Every figure is regenerated by `code/make_figures.py` (Figs. 2–5) or `figures/fig1_geometry.tex`; nothing is edited by hand.

## Key results (all produced by the code)

* Outer-face heating bows the pinned strip **away from the channel**; free curvature κ_th = (1+ν)α q″/k_s = 1.4 m⁻¹,
  independent of thickness; the passage widens.
* Baseline (H0 = 0.5 mm, L = 30 mm, d = 3 mm, U = 0.05 m/s, q″ = 5 kW/m², Re = 50, PEEK-class strip):
  w_max = 0.428 H0 (self-consistent beam–column), 0.438 H0 (frozen force), 0.444 H0 (2-D nonlinear FE).
  The 3.8 % FE–beam difference is a finite-thickness effect (0.9 % at d/L = 0.05, −0.2 % at 0.025).
* Two independent FE codes agree to 0.02 %.
* Guards (frozen force): w/H0 = 0.5 at 5.5 kW/m², stress cap at 6.0 kW/m², buckling margin 2 at 9.1 kW/m².
* Γp = 1714 (like-for-like). Flow-side estimates (≈ 50 % lower pressure drop, ×1.29 wall excess) are indicative only.
