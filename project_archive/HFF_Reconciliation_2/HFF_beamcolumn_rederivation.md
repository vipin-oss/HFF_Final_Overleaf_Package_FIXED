# Independent re-derivation: pinned–pinned beam–column bowing at finite membrane force

**Status:** adopted as the baseline wall relation (document eqs. 4.9–4.11; cell A9; register
D-15). This note records the derivation path, the checks against limiting cases, and the
numerical evaluation at the baseline operating point.

## 1. Model level and hypotheses

* Kinematics: von Kármán — infinitesimal strain, moderate rotation. Justification at the
  baseline: bending fibre strain 9.9×10⁻⁴, arc strain 1.5×10⁻⁴, maximum slope 0.027 rad,
  maximum total mechanical surface strain 5.4×10⁻³ — all ≪ 1. No large-deformation extension is
  introduced; this is the *minimal* model level consistent with the strip's own membrane state.
* Wall: plane-strain wide-plate strip, thickness d = 3 mm, length L = 30 mm, flexural rigidity
  per unit depth D_s = E d³/[12(1−ν²)] = 9.6 N·m.
* Supports: pinned–pinned on the full end edges (A9): w = 0 and M = 0 at x = 0, L.
* Loading: uniform eigen-curvature κ_th = (1+ν) α q″/k_s = 1.4 m⁻¹ plus a compressive axial
  (membrane) force N_θ^c = |N_θ| = 2.9×10⁴ N/m arising from the blocked thermal expansion,
  N_θ = −E d α θ̄/(1−ν) with θ̄ = 32.3 K (derived in §1b below).

### 1b. Membrane force re-derived from the constitutive assumptions (erratum ERR-01 resolved here)

State: plane-strain strip, free lateral (outer/inner) faces (σ_yy = 0), through-thickness
coordinate suppressed, uniform mean rise θ̄, axial displacement blocked at the end edges
(ε_xx = 0 in the mean). Plane strain sets ε_zz = 0. With the isotropic thermoelastic law
ε = σ/E − ν(tr σ − σ)/… written componentwise:

* ε_zz = 0 gives σ_zz = ν σ_xx − E α θ̄.
* ε_xx = σ_xx/E − ν(σ_yy + σ_zz)/E + α θ̄ = 0; substituting σ_yy = 0 and σ_zz:
  σ_xx(1 − ν²)/E + α θ̄(1 + ν) = 0 ⟹ **σ_xx = −E α θ̄/(1−ν)**.
* Membrane force per unit depth: **N_θ = d σ_xx = −E d α θ̄/(1−ν)**.

Numerically: N_θ = −(3.6×10⁹)(3×10⁻³)(5×10⁻⁵)(32.3)/0.6 = **−2.91×10⁴ N/m**;
N_cr = π²D_s/L² = 9.87 × 9.6/9×10⁻⁴ = 1.053×10⁵ N/m; **N/N_cr = 0.276 ≈ 0.275** — consistent
with Chapter 4 (eq. eq:ntheta), Table 7.1, and cell A5. Had the factor 2 been real, N/N_cr would
be 0.55, contradicting every recorded value; the number was always computed from the
single-factor law.

**Erratum ERR-01 (this note, earlier revision).** This note and two reconciliation CSV rows
previously transcribed the force as N_θ = −2Eαθ̄/(1−ν)·d while quoting the correct numerical
value 2.9×10⁴ N/m. The stray factor originates in the *mean-stress* coefficient of the same
restrained state, σ_m = (σ_xx + σ_zz)/3 = −2Eαθ̄/[3(1−ν)] (register EQ-09/V-C1b): dropping the 3
from that expression reproduces the erroneous force form. The Chapter-4 equation, Table 7.1, the
Stage-1 audit (CAL-11), and all numerical results were and are correct; only the transcription
in the Stage-2 reconciliation layer was fixed (see `HFF_correction_report_v2a.md`).

## 2. Governing equation

For the strip with total curvature κ = w″ + κ_th, bending moment M = D_s κ, and axial force
N = −N_θ^c (compression), transverse equilibrium of a beam element gives, per unit depth,

  D_s w⁗ + N_θ^c w″ = 0,  w(0) = w(L) = 0,  w″(0) = w″(L) = −κ_th .

The moment boundary condition states M = 0 at the pins (moment-free ends). Note the axial force
is a *data* of the thermoelastic state, not an independent load: it is generated by the same θ̄
that generates κ_th.

## 3. Solution

With μ² = N_θ^c/D_s the general solution of w⁗ + μ² w″ = 0 is w = A + Bx + C cos μx + D sin μx.
Imposing w(0) = w(L) = 0 and w″ = −κ_th at both ends:

  w(x) = (κ_th/μ²) [ (1 − cos μL)/sin μL · sin μx + cos μx − 1 ]

(document eq. 4.10). Properties:

* **Linear limit.** μL → 0: expanding cos/sin to O((μL)²) recovers the parabola
  w = (κ_th/2) x (L−x), w_max = κ_th L²/8 — the zero-force (Euler–Bernoulli bowing) result.
* **Buckling limit.** sin μL → 0 (μL = π) with κ_th ≠ 0: w diverges — exactly the pinned Euler
  threshold N_cr = μ² D_s = π² D_s/L². Deflection law and buckling ceiling are two limits of one
  relation, as they must be.
* **Amplification.** For small force, w_max/w_max^lin → 1/(1 − N/N_cr) at leading order.

## 4. Baseline evaluation

Inputs: κ_th = 1.4 m⁻¹; D_s = 9.6 N·m; N_θ^c = 2.9×10⁴ N/m; N_cr = π²×9.6/9×10⁻⁴
= 1.06×10⁵ N/m; N/N_cr = 0.275; μ = √(2.9×10⁴/9.6) = 55 m⁻¹; μL = 1.65.

* w_max = (κ_th/μ²)[(1 − cos 1.65)/sin 1.65 × 1 + cos 1.65 − 1]×10⁻² m form →
  **w_max = 2.19×10⁻⁴ m = 0.438 H₀** (1.39 × linear). Leading-order factor
  1/(1−0.275) = 1.38 — consistent to 1%.
* Maximum slope w′_max = 0.027 rad.
* Mid-span moment M_mid = D_s (w″(L/2) + κ_th) = −6.4 N·m per unit depth;
  σ_bend = 6|M_mid|/d² = 4.2 MPa.
* Self-consistency of the constant-force assumption: deflection relaxes the blocked-end
  membrane strain e₀ = α θ̄ (1+ν) = 2.1×10⁻³ by the arc-stretching fraction
  κ_geo² L²/24 = 1.5×10⁻⁴, i.e. ≈7% force relaxation — second order, assumption stands.
* Combined stress: σ_memb = −9.7 MPa (uniform) + σ_bend ±4.2 MPa → |σ|_max ≈ 13.9 MPa
  = 0.15 σ_y (band edge 90 MPa): inside the A-6 design cap 0.2 σ_y with margin ≥ 6.

## 5. Admissibility re-derivation (bound A-3 at the new model level)

* Bending fibre strain (κ_geo − κ_th) d/2 = (2.06 − 1.4)×1.5×10⁻³ = 9.9×10⁻⁴ ≤ 5×10⁻³ ✓
* Total mechanical surface strain ≈ 5.4×10⁻³ ≤ 10⁻² ✓
* Arc strain 1.5×10⁻⁴ ≤ 10⁻³ ✓; slope 0.027 rad ≤ 0.1 rad ✓
* Mesh-generation bound |w|/H₀ ≤ 0.5 with positive Jacobians: baseline 0.438 ✓ (0.5 is a
  discretization limit, not a physics bound; the earlier 0.35 figure is superseded).

## 6. Design-space consequence (ordering of ceilings)

All three ceilings scale ∝ q″; at the baseline geometry:

| Ceiling | Basis | q″ at ceiling |
|---|---|---|
| A-3 mesh bound (w/H₀ = 0.5) | 0.315 r/(1−0.275 r) = 0.5 → r = 1.105 | ≈ 1.0×10⁴ W/m² |
| A-6 stress cap (0.2 σ_y) | σ_tot ∝ q″: 13.9 MPa → 18 MPa at r = 1.295 | ≈ 1.16×10⁴ W/m² |
| A-2 buckling margin (M_b = 2) | θ̄ = 58.7 K at r = 1.818 | ≈ 1.6×10⁴ W/m² |

The earlier statement "the binding constraint is buckling" is corrected: deformation kinematics
and the stress cap bind first; buckling is the outer ceiling.

## 7. Disposition of the alternatives (why this correction is the smallest justified one)

* **Keep the linear relation at the baseline** — rejected: internally inconsistent (the model
  asserts the buckling ceiling that arises from the very N–w coupling the linear relation omits).
* **Detune the operating point** (q″ ≈ 1.5–2 kW/m², N/N_cr ≲ 0.1) — rejected as a *correction*:
  it would silently change the reported operating point; retained as an option for validation
  cases (the load-case additivity check runs at N/N_cr ≤ 0.05).
* **Full large-deflection (finite-rotation) model** — rejected: unjustified by the kinematics
  (slopes 0.027 rad) and would be model inflation to chase nothing.
* No geometry, material, or operating parameter was altered.
